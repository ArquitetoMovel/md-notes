Por Que Criamos o mdn?

Chega de perder o foco alternando para editores gráficos pesados

Desenvolvedores que usam assistentes de IA no terminal (como Antigravity CLI, Claude Code e Aider) perdem tempo precioso e fluxo cognitivo ao abrir navegadores ou IDEs de 500 MB apenas para revisar um README ou plano de execução.

Editores Simples (Nano / Vi)

Monocromáticos e Limitados

  • Markdown cru sem hierarquia visual de títulos ou ênfases
  • Tabelas quebram alinhamento ao editar no terminal
  • Sem sincronização nativa com a área de transferência
Neovim / Emacs Custom

Configuração Complexa

  • Exige dezenas de plugins Lua/Vimscript instáveis
  • Setup quebra com atualizações e não é portátil para servidores
  • Plugins Markdown ocultam a sintaxe crua, dificultando commits
A Solução Definitiva

md-notes (mdn)

  • Zero configuração: Binário nativo único de 3.5 MB pronto para rodar
  • Ergonomia Vim total: Atalhos h/j/k/l, dd, yy, u, :s e popup de settings :c
  • Tabelas dinâmicas: Alinhamento automático inteligente enquanto você digita
  • Não-destrutivo: Marcadores (#, **, `) ficam visíveis e atenuados
  • Gravação Atômica: Zero risco de corrupção com fsync e renomeação segura
Engenharia e Arquitetura

Os 8 Pilares do md-notes

Construído rigorosamente sobre The Elm Architecture (Bubble Tea) com modelo de dados em runes UTF-8, separação total entre máquina modal de estados e camada de apresentação.

RECURSO F01

CLI Entrypoint & Buffer Manager

Suporte flexível a mdn doc.md, buffer temporário scratchpad e pipes stdin (cat file | mdn). Possui detecção automática de modificações externas e alerta contra saída acidental sem salvar (E37).

Stdin Pipe fsnotify Watcher Scratchpad
RECURSO F02

Motor de Configuração & Temas TOML

Configurações limpas em config.toml (XDG e AppData). Inclui 7 temas completos embutidos (Dracula, Nord, Catppuccin Mocha/Macchiato, Monokai, Tokyo Night, Light) e substituições RGB/Hex arbitrárias.

TOML Parser 7 Paletas Hot-Reload
RECURSO F03

Motor Modal de Edição (Vim Nativo)

Modos Normal, Insert, Visual (por caractere, linha e bloco), Command (:w, :q) e Busca. Contadores numéricos (5dd, 3w), área de transferência sincronizada e 200 níveis de undo/redo.

Modos Vim Clipboard Sync 200 Undo/Redo
RECURSO F04

Parser Markdown Vivo & Chroma

Tokenização incremental não-destrutiva a 60 FPS. Os caracteres de formatação (#, *, _, `) permanecem no buffer com tom atenuado (dimmed), enquanto blocos de código recebem syntax highlighting inteligente.

AST Incremental Dimmed Markers Chroma Syntax
RECURSO F05

Dynamic Markdown Table Engine

Detecção instantânea de tabelas com autoalinhamento inteligente de colunas durante a digitação. Cálculo visual exato via go-runewidth (multibyte, emojis e CJK) e navegação confortável por células com Tab.

Auto-Align go-runewidth Tab Nav
RECURSO F06

Busca Incremental & Substituição Regex

Pressione / ou ? para saltos imediatos e visualização realçada de todos os matches na tela. Navegue com n / N e substitua com :s/de/para/g ou :%s em todo o documento.

Incremental Search Regex Engine :%s/de/para/g
RECURSO F07

Viewport TUI & Statusline Powerline

Rolagem suave com scrolloff configurável, números de linha absolutos ou relativos (relativenumber) e status bar dividida com indicação de modo, arquivo sujo [+], encoding, linha/coluna e porcentagem.

Relative Numbers Smooth Scroll Zero Flickering
RECURSO F08

Painel de Configurações Interativo (:c)

Execute :c ou :config no modo Normal para abrir uma janela modal popup centralizada. Alterne temas com live preview no viewport de fundo, ajuste tamanho do tab, wrap e edite cores hexadecimais com persistência direta.

Popup Modal Live Preview Inline Hex Edit
